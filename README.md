# LeagueLoop Installer

Standalone one-click installer for **LeagueLoop**.

## Download

Download the latest automated setup executable:
- [**LeagueLoop_Installer.exe**](./LeagueLoop_Installer.exe) (Version `1-08-149-0242`)

## Features
- **Zero-Dependency Setup**: Bundles Python runtime, dynamic libraries, PySide6, CustomTkinter assets, and certificate authority configs.
- **One-Click Installation**: Standalone wizard configures installation paths and desktop icons automatically.
- **Auto-Clean Protocol**: Automatically resolves stale runtime log handles upon upgrade/reinstallation.
